# CSGO-Player-Statistics-Dashboard

This project is an interactive Power BI dashboard designed to analyse and compare the performance of professional CS:GO players using data obtained from HLTV. These two players were regarded the best of 2024, so I compared who is better.

The Overview page provides a visual comparison between donk and jL, displaying key performance metrics in 2024. The dashboard allows users to explore player performance through interactive visuals and a player selection filter.

Dashboard features I have added:
Player Rating Timeline : compares how each player's performance rating changes throughout 2024.
Kill/Death Ratio (K/D) : displays and compares the average kill-to-death ratio of both players.
Kills Per Round (KPR) : shows the average number of kills achieved per round.
Win Rate : displays the percentage of recorded matches won.
Overall Player Rating : compares the overall performance rating of each player.
Total Kills & Deaths : visualises the total number of kills and deaths recorded for each player.
Weapon Kill Analysis : compares the number of kills achieved using different weapon categories, including rifles and pistols.
Interactive Player Selection : allows users to filter the dashboard and explore statistics for individual players.
Glossary Page : provides simple definitions of the key CS statistics used throughout the dashboard, including Total Kills, Total Deaths, Maps Played, Rifle Kills, Pistol Kills, Win Rate, Kills Per Round and Player Rating.

I have added a Glossary Page which provides definitions for the statistics and terminology used throughout the dashboard.

The dashboard was created to transform raw CS statistics into a clear, interactive and easy-to-understand visual analysis, while demonstrating my skills in Power BI, data visualisation and data analysis.
